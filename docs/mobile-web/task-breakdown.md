# 手机网页版任务拆分步骤文档

## 1. 梳理现有桌面版结构

- 确认桌面端哪些模块可复用。
- 确认上传区、参数区、预览区、统计区的现状。
- 明确手机端不能直接沿用双栏工作台布局。

## 2. 设计手机信息结构

- 重新定义手机端模块顺序。
- 优先保证预览区在首屏可见。
- 规划上传、参数、统计在手机端的展开方式。

## 3. 调整页面布局

- 桌面端继续保留双栏布局。
- 手机端改为单列布局。
- 控制卡片间距、标题层级和按钮尺寸。

## 4. 优化上传区

- 让上传入口适合手指点击。
- 保持原图完整预览。
- 避免图片撑坏卡片高度。

## 5. 优化参数区

- 让底板尺寸和色卡按钮适合小屏排列。
- 调整滑块、说明文案和合并强度按钮。
- 保证生成按钮在手机上清晰突出。

## 6. 优化预览区

- 保持正方形预览区。
- 保证预览区在手机上尽量靠前。
- 让预览在小屏下可滚动查看。
- 评估小尺寸时是否隐藏色号。

## 7. 优化统计区

- 优化统计卡片在手机上的排版。
- 优化颜色列表的单行布局。
- 保证导出按钮明显且易点击。

## 8. 优化整体视觉节奏

- 统一卡片高度节奏和留白。
- 控制手机端首屏信息密度。
- 保持 CuteBead 当前视觉风格一致。

## 9. 验证交互流程

- 验证上传图片 -> 设置参数 -> 生成图纸 -> 查看统计 -> 导出流程。
- 验证不同底板尺寸在手机端的显示情况。
- 验证导出按钮和错误提示在手机端可用。

## 10. 第一版收尾

- 清理无用样式。
- 检查空状态和错误提示。
- 检查桌面端是否被意外破坏。
- 完成第一版可用的手机网页版。

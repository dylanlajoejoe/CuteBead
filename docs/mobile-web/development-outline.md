# 拼豆图纸生成器手机网页版开发大纲

## 1. 产品定位

- 手机网页版沿用现有 Web 核心能力：上传图片 -> 设置参数 -> 生成图纸 -> 预览图纸 -> 查看统计 -> 保存图片。
- 重点目标是让用户在手机浏览器中也能顺畅生成和查看图纸。
- 手机版不直接照搬桌面双栏工作台，而是改为单列流程式布局。

## 2. 底板尺寸选择

- 支持 `52 / 78 / 104 / 208` 四种正方形拼豆底板。
- 默认选择 `104 x 104`。
- 生成、预览、统计和导出都按当前底板尺寸处理。

## 3. 色卡选择

- 支持 `72 / 96 / 144 / 221` 四套色卡。
- 生成时只使用当前选择的色卡。
- 统计区输出 MARD 色号和数量。

## 4. 图片上传

- 支持手机从相册上传图片。
- 支持 PNG、JPG、WEBP。
- 上传区显示完整原图预览，图片适配固定预览区，不拉伸。
- 处理上传失败、格式错误和空状态。

## 5. 参数设置

- 支持底板尺寸选择。
- 支持色卡选择。
- 支持合并强度 `低 / 中 / 高`。
- 支持图案大小百分比调节。
- 生成按钮在未上传图片时禁用。

## 6. 图纸生成逻辑

- 沿用现有网页版图纸生成算法。
- 保留小面积高对比细节增强逻辑。
- 保留按色卡最近色匹配和全图颜色频率合并。
- 输出图纸数据、颜色统计和总豆数。

## 7. 手机端图纸预览

- 预览区保持正方形。
- 预览区作为首屏核心视觉区域。
- 小屏幕下优先保证图纸可缩放、可拖动或可滚动查看。
- 小格较小时可隐藏色号，避免拥挤。

## 8. 统计与导出

- 展示总豆数、颜色数和底板尺寸。
- 展示每个 MARD 色号数量。
- 支持导出 PNG。
- 导出图中包含网格、色号和颜色统计。

## 9. 手机 UI 结构

- 页面采用单列布局。
- 首屏优先展示预览区。
- 上传和参数区采用卡片式分段布局。
- 统计区默认放在预览区下方，避免与预览争抢空间。
- 关键按钮应固定明显，避免用户频繁寻找入口。

## 10. 体验优化重点

- 减少长距离滚动。
- 保证点击区域足够大。
- 保证文字和色号在手机上仍可辨识。
- 预留后续“整图 / 分区查看”模式的扩展空间。

## 11. 第一版不做

- 不做账号系统。
- 不做小程序专属能力。
- 不做手动改色。
- 不做自动去背景。
- 不做多品牌色号切换。

## 12. 开发建议

- 直接在现有 Web 项目上增加手机端布局分支。
- 继续复用现有算法、色卡和导出逻辑。
- 先完成手机单列版，再视需要补分区查看模式。

# 前端设计文档

## 1. 页面目标

第一版只做一个单页工具，完成“上传图片 -> 设置参数 -> 生成图纸 -> 查看统计 -> 导出 PNG”的完整流程。

## 2. 页面结构

页面分为四个区域：

- 上传区：上传图片，显示原图缩略图。
- 设置区：选择色卡、设置图纸宽高、选择合并强度。
- 预览区：显示生成后的拼豆图纸。
- 统计区：显示总豆数、颜色数量和导出按钮。

## 3. 桌面端布局

桌面端采用左右分栏：

- 左侧：上传区、设置区、统计区。
- 右侧：图纸预览区。
- 右侧预览区域优先占用更大空间。

## 4. 移动端布局

移动端按纵向排列：

- 上传图片。
- 设置参数。
- 查看预览。
- 查看统计。
- 导出图纸。

## 5. 上传区

需要包含：

- 点击上传按钮。
- 拖拽上传区域。
- 原图缩略图。
- 重新上传入口。

支持格式：

- PNG
- JPG / JPEG
- WEBP

## 6. 设置区

需要包含：

- 色卡选择：`72 / 96 / 144 / 221`。
- 图纸宽度输入。
- 图纸高度输入。
- 合并强度选择：低 / 中 / 高。
- 生成按钮。

限制：

- 宽度最大 `100`。
- 高度最大 `100`。
- 宽高必须大于 `0`。

## 7. 预览区

第一版只做图纸预览。

预览内容：

- 每个格子显示对应颜色。
- 每个格子显示 MARD 色号。
- 每 `5` 格显示虚线。
- 每 `10` 格显示黑色实线。
- 按 `20x20` 拼豆板规则显示辅助网格。

## 8. 统计区

需要显示：

- 图纸尺寸。
- 总豆数。
- 使用颜色数。
- 每个颜色的色块、MARD 色号、数量。
- 导出 PNG 按钮。

## 9. 视觉风格

整体风格是“清新、可爱、手作感”，主视觉偏绿色。

关键词：

- 清新：浅色、通透、干净。
- 可爱：圆角、柔和色块、小装饰。
- 手作感：像桌面上的手工材料盒，不像冷冰冰的后台工具。
- 专业可读：图纸、色号、统计信息必须清楚。

避免：

- 大面积高饱和紫色。
- 纯后台表单风格。
- 过重阴影。
- 复杂花哨导致图纸不可读。

## 10. 设计系统

为了后续新增界面可以复用，第一版需要建立稳定的设计 token。

### 10.1 颜色

基础色：

- 页面背景：`#FFF9F0`，温暖奶油白。
- 卡片背景：`#FFFFFF`，保持内容清晰。
- 主色：`#8FD694`，清新的嫩绿色。
- 主色深色：`#58B368`，用于重要按钮悬停。
- 辅助色：`#FFB86B`，用于提示、点缀和强调。
- 可爱点缀：`#FF8FAB`，用于小标签和轻量装饰。
- 成功色：`#7BC96F`。
- 警告色：`#F7C948`。
- 错误色：`#F97066`。

文字色：

- 主文字：`#2F2A25`。
- 次级文字：`#776B60`。
- 弱提示文字：`#A39487`。
- 反白文字：`#FFFFFF`。

边框色：

- 普通边框：`#F1E3D3`。
- 强调边框：`#BFEDE7`。
- 虚线边框：`#E8D8C8`。

### 10.2 圆角

圆角统一使用以下层级：

- 小组件：`10px`。
- 输入框、按钮：`14px`。
- 普通卡片：`20px`。
- 重点区域卡片：`28px`。
- 圆形装饰和色块：`999px`。

### 10.3 阴影

阴影要轻，表现“纸张和手作材料”的层次。

- 普通卡片：`0 8px 24px rgba(92, 71, 50, 0.08)`。
- 悬浮卡片：`0 16px 40px rgba(92, 71, 50, 0.12)`。
- 按钮阴影：`0 8px 16px rgba(143, 214, 148, 0.28)`。

### 10.4 间距

使用稳定间距，避免页面越做越乱。

- 页面外边距：移动端 `16px`，桌面端 `32px`。
- 卡片内边距：移动端 `16px`，桌面端 `24px`。
- 区块间距：`20px`。
- 表单项间距：`12px`。
- 小元素间距：`8px`。

### 10.5 字体

中文优先选择圆润、清新的字体。

推荐：

- 标题：`LXGW WenKai` 或类似圆润中文字体。
- 正文：`Noto Sans SC` 或类似清晰中文字体。

如果不引入外部字体，使用系统中文字体兜底，但标题仍要通过字重、字号、间距做出可爱感。

## 11. 可复用组件风格

后续所有页面和功能都按这些组件风格扩展。

### 11.1 Button

按钮分三类：

- 主按钮：薄荷蓝绿背景，白色文字，用于“生成图纸”“导出 PNG”。
- 次按钮：白底、薄荷色边框，用于“重新上传”“重置”。
- 轻按钮：无背景或浅色背景，用于辅助操作。

按钮状态：

- 默认：圆角、轻阴影。
- 悬停：颜色略深，轻微上浮。
- 禁用：低透明度，不可点击。

### 11.2 Card

卡片是页面主要容器。

规则：

- 白色背景。
- 大圆角。
- 轻阴影。
- 顶部可以有小标题和说明。
- 重要卡片可以加浅色渐变边框。

### 11.3 Input

输入框风格：

- 白色或淡奶油色背景。
- `14px` 圆角。
- 普通边框。
- 聚焦时使用薄荷色边框和浅色外发光。

### 11.4 Select / Segmented Control

色卡选择和合并强度建议使用分段选择器。

规则：

- 未选中为浅色底。
- 选中为主色背景。
- 显示简短标签，例如 `72色`、`96色`、`144色`、`221色`。

### 11.5 Color Count Item

颜色统计项需要清楚可读。

包含：

- 颜色圆点或圆角方块。
- MARD 色号。
- 数量。

建议做成紧凑列表，避免占用过多空间。

## 12. 图纸视觉规则

图纸区域优先保证可读性。

规则：

- 图纸背景使用白色或浅灰白。
- 每格色块使用真实色卡颜色。
- 色号文字根据格子颜色自动选择黑色或白色。
- 每 `5` 格画虚线。
- 每 `10` 格画黑色实线。
- 图纸外层使用浅色卡片包裹。
- 预览区需要支持滚动，避免大图压缩到不可读。

## 13. 空状态

未上传图片时：

- 上传区显示可爱提示文案。
- 预览区显示浅色插画感占位。
- 统计区显示空状态。
- 导出按钮不可用。

建议文案：

- “上传一张图片，开始变成拼豆图纸。”
- “选择色卡和尺寸后，就能看到图纸啦。”

## 14. 反馈状态

需要覆盖以下状态：

- 生成中：按钮显示加载状态。
- 生成成功：显示统计和预览。
- 生成失败：显示错误提示。
- 参数错误：在输入框附近显示提示。
- 导出失败：显示轻量提示。

提示风格：

- 使用浅色背景。
- 圆角。
- 不使用强烈弹窗打断用户。

## 15. 可持续扩展规则

后续新增界面时遵守：

- 优先复用颜色 token，不随意新增主色。
- 优先复用 Card、Button、Input、Segmented Control。
- 新功能先放进现有卡片结构，必要时再拆页面。
- 图纸相关界面始终优先保证可读性。
- 装饰元素只能辅助氛围，不能影响操作。
- 新增统计、清单、设置项都保持相同标题、间距、圆角和阴影体系。

## 16. 推荐页面氛围

页面可以像一个“绿色拼豆小工作台”：

- 背景像柔和纸张。
- 卡片像放在桌面上的材料盒。
- 色卡像小豆子排列。
- 操作流程像一步步做手工。

这套风格适合后续扩展到作品保存、图纸历史、色卡管理等页面。

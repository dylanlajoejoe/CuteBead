# 任务拆分步骤文档

## 1. 项目初始化

- 初始化前端项目。
- 配置 TypeScript。
- 配置基础样式。
- 整理目录结构。

## 2. 色卡加载

- 接入 `72 / 96 / 144 / 221` 四套色卡。
- 实现色卡选择。
- 将色卡转换为生成算法可用的数据。

## 3. 图片上传

- 实现图片上传入口。
- 支持 PNG、JPG、WEBP。
- 显示原图缩略图。
- 处理上传失败和格式错误。

## 4. 参数设置

- 实现图纸宽高输入。
- 限制最大 `100x100`。
- 实现合并强度选择。
- 实现生成按钮状态控制。

## 5. 图纸生成

- 使用 Canvas 读取图片像素。
- 按用户设置的宽高切分图片。
- 提取每格主色。
- 匹配当前色卡最近颜色。
- 执行全图颜色频率合并。
- 生成图纸数据。

## 6. 图纸预览

- 绘制方格图纸。
- 每格显示颜色。
- 每格显示 MARD 色号。
- 每 `5` 格绘制虚线。
- 每 `10` 格绘制黑色实线。

## 7. 颜色统计

- 统计总豆数。
- 统计使用颜色数。
- 统计每个 MARD 色号数量。
- 展示颜色清单。

## 8. PNG 导出

- 导出当前图纸为 PNG。
- PNG 中包含网格、色号和统计信息。
- 处理导出失败情况。

## 9. 页面适配

- 桌面端左右分栏。
- 移动端纵向排列。
- 保证预览区可滚动和缩放查看。

## 10. 基础验证

- 验证四套色卡都能生成图纸。
- 验证不同尺寸能正常生成。
- 验证颜色统计正确。
- 验证 PNG 可以正常下载。
- 验证超过尺寸限制时能正确提示。

## 11. 第一版收尾

- 清理无用代码。
- 检查空状态和错误提示。
- 检查文案一致性。
- 完成第一版可用工具。

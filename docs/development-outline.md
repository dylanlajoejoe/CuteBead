# 拼豆图纸生成器开发大纲

## 1. 颜色数选择

- 已有 `72 / 96 / 144 / 221` 四套色卡。
- 用户可以选择颜色数。
- 生成图纸时只使用当前选择的色卡。
- 颜色清单按当前色卡输出 MARD 色号和数量。

## 2. 前端界面

- 第一版只做 `1` 个页面。
- 页面流程为：上传图片 -> 设置参数 -> 预览图纸 -> 查看统计 -> 导出 PNG。
- 上传区：上传图片并显示原图缩略图。
- 设置区：选择色卡、设置图纸宽高、选择合并强度。
- 预览区：显示生成后的图纸、色号和底板辅助线。
- 统计区：显示总豆数、每种颜色数量和导出按钮。
- 移动端按纵向排列，桌面端可以左右分栏。

## 3. 图纸尺寸方式

- 符合拼豆用户心智的“拼豆板尺寸”。
- 支持用户设置 `宽 x 高`。
- 显示最终图纸总格数和预计豆子数量。

## 4. 最大尺寸限制

- 第一版限制最大尺寸，避免浏览器卡顿。
- 最大 `100x100`。
- 后续如果需要支持大图，再加入 Web Worker。

## 5. 预览效果

- 图纸预览：使用方格、网格线和色号，方便照着摆。

## 6. 导出图纸

- 支持导出 PNG。
- 导出图中显示网格线。
- 导出图中显示色号。
- 导出图中包含颜色统计。

## 7. 底板辅助

- 按 `20x20` 拼豆板显示辅助网格。
- 每 `10` 格显示黑色实线，表示大网格边界。
- 每 `5` 格显示虚线，表示辅助小框边界。
- 每个虚线小框包含 `5x5 = 25` 个拼豆摆放区域。
- 后续支持按底板分页打印。

## 8. 全图颜色频率合并

- 高频颜色优先保留。
- 相近的低频颜色合并到高频颜色。
- 用于减少杂色，让图纸更适合实际拼豆。

## 9. 第一版不做

- 不做手动改色。
- 不做自动去背景。
- 不做 CSV 导入导出。
- 不做 PWA。
- 不做多页面。
- 不做多品牌色号切换。

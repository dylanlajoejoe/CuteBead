# 功能实现文档

## 1. 第一版目标

实现一个单页拼豆图纸生成器。

用户上传图片后，可以选择色卡和尺寸，生成带色号和辅助线的拼豆图纸，并导出 PNG。

## 2. 功能范围

第一版实现：

- 图片上传。
- 色卡选择：`72 / 96 / 144 / 221`。
- 图纸宽高设置。
- 主色取色。
- 色卡最近色匹配。
- 全图颜色频率合并。
- 图纸预览。
- 颜色数量统计。
- PNG 导出。

第一版不实现：

- 手动改色。
- 自动去背景。
- CSV 导入导出。
- PWA。
- 多页面。
- 多品牌色号切换。

## 3. 生成流程

完整流程：

1. 用户上传图片。
2. 前端读取图片并生成 `HTMLImageElement`。
3. 用户选择色卡数量。
4. 用户设置图纸宽高。
5. 用户选择合并强度。
6. 点击生成。
7. Canvas 读取原图像素。
8. 按宽高切分图片区域。
9. 每个区域提取主色。
10. 主色匹配到当前色卡中最接近的颜色。
11. 对整张图进行颜色频率合并。
12. 生成图纸数据。
13. 统计每种颜色数量。
14. Canvas 绘制图纸预览。
15. 用户导出 PNG。

## 4. 图片处理

图片上传后，需要：

- 校验文件类型。
- 读取为图片对象。
- 绘制到隐藏 Canvas。
- 获取像素数据。

每个拼豆格子对应原图中的一个矩形区域。

## 5. 主色提取

每个格子使用主色模式。

规则：

- 统计该区域内出现次数最多的颜色。
- 忽略透明像素。
- 如果区域没有有效像素，则使用白色或空白处理。

## 6. 色卡匹配

每个格子的主色需要匹配到当前色卡中最近的颜色。

规则：

- 当前色卡由用户选择。
- 第一版只输出 MARD 色号。
- 匹配结果保存为颜色 HEX 和 MARD 编号。

## 7. 全图颜色频率合并

保留该逻辑。

规则：

- 先统计整张图中每种颜色出现次数。
- 高频颜色优先保留。
- 低频颜色如果和高频颜色足够接近，则合并到高频颜色。
- 合并强度影响颜色距离阈值。

建议：

- 低：弱合并，保留更多细节。
- 中：默认强度。
- 高：强合并，减少更多杂色。

## 8. 图纸预览

第一版只做图纸预览。

绘制规则：

- 每个拼豆位置绘制为一个方格。
- 方格填充匹配后的颜色。
- 方格中心显示 MARD 色号。
- 每 `5` 格绘制虚线。
- 每 `10` 格绘制黑色实线。
- 按 `20x20` 拼豆板辅助规则展示。

## 9. 颜色统计

生成图纸后统计：

- 总豆数。
- 使用颜色数。
- 每个 MARD 色号对应的数量。

统计列表按 MARD 色号排序。

## 10. PNG 导出

导出内容包括：

- 图纸主体。
- 网格辅助线。
- 每格 MARD 色号。
- 颜色统计信息。

导出文件名建议：

```text
cutebead-pattern-{width}x{height}-{paletteSize}.png
```

## 11. 尺寸限制

第一版限制：

- 最大宽度：`100`。
- 最大高度：`100`。
- 最小宽度：`1`。
- 最小高度：`1`。

超过限制时不生成，并提示用户。

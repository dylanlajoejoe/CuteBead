# 小程序任务拆分步骤文档

## 1. 工程初始化

- 新建 `miniprogram/` 小程序工程目录。
- 配置基础项目结构、页面路由和开发配置。
- 约定与网页版共享代码的目录结构。

## 2. 共享层抽离

- 抽离色卡数据。
- 抽离类型定义。
- 抽离颜色匹配、频率合并、图纸生成等纯算法逻辑。
- 保证共享代码不依赖浏览器 DOM。

## 3. 小程序基础页面搭建

- 创建首页。
- 搭建单列移动端布局。
- 预留上传区、参数区、预览区和统计区。
- 完成基础样式和交互状态。

## 4. 图片选择与预览

- 接入小程序图片选择 API。
- 支持从相册选择图片，必要时支持拍照。
- 显示完整原图预览。
- 处理异常图片、超大图片和读取失败提示。

## 5. 参数设置功能

- 实现 `52 / 78 / 104 / 208` 底板选择。
- 默认底板设为 `104 x 104`。
- 实现 `72 / 96 / 144 / 221` 色卡选择。
- 实现合并强度选择。
- 实现图案大小百分比调节。
- 实现生成按钮禁用和加载状态。

## 6. 图纸生成能力接入

- 在小程序环境读取图片像素。
- 按底板尺寸计算图案区域。
- 生成图纸单元颜色、MARD 色号和偏移信息。
- 接入细节增强策略，尽量保留五官和线条。
- 生成颜色统计结果。

## 7. 图纸预览绘制

- 在预览区绘制正方形底板。
- 绘制拼豆颜色块。
- 绘制 `5` 格虚线和 `10` 格实线辅助网格。
- 根据缩放级别决定是否显示色号。
- 处理拖动、缩放或局部查看。

## 8. 统计区实现

- 展示底板尺寸。
- 展示总豆数。
- 展示颜色数。
- 展示每个 MARD 色号数量列表。

## 9. 图纸保存功能

- 生成可保存的图纸图片。
- 图中包含网格、色号和统计信息。
- 接入保存到相册能力。
- 处理权限拒绝和保存失败提示。

## 10. 手机端体验优化

- 优化首屏布局，优先保证预览区可见。
- 优化按钮大小和点击区域。
- 优化长列表滚动和统计展示。
- 评估是否增加整图 / 分区查看切换。

## 11. 性能优化

- 检查 `52 / 78 / 104 / 208` 四种底板的生成耗时。
- 检查连续生成时的内存占用。
- 对 `208 x 208` 做重点优化。
- 必要时引入分批绘制或 Worker。

## 12. 权限与异常处理

- 处理相册读取权限。
- 处理相册保存权限。
- 处理用户拒绝授权后的指引文案。
- 处理生成失败、保存失败和资源释放问题。

## 13. 真机验证

- 在微信开发者工具中完成基础流程验证。
- 在 iPhone 和安卓真机上测试上传、生成、预览、保存。
- 验证不同底板尺寸和不同类型图片的结果。
- 验证手机端操作是否清晰、不累。

## 14. 第一版收尾

- 清理无用代码。
- 检查空状态、错误提示和权限提示。
- 检查文案一致性。
- 完成第一版可试用的小程序。

# 拼豆图纸生成器小程序开发大纲

## 1. 产品定位

- 小程序版沿用网页版核心能力：上传图片 -> 设置参数 -> 生成图纸 -> 预览图纸 -> 查看统计 -> 保存图片。
- 小程序版重点面向手机端使用和分享传播。
- 页面结构以单列流程为主，优先保证预览区和生成流程清晰。

## 2. 底板尺寸选择

- 支持 `52 / 78 / 104 / 208` 四种正方形拼豆底板。
- 默认选择 `104 x 104`。
- 用户选择底板后，图纸生成、预览、统计和导出都按当前底板尺寸处理。

## 3. 色卡选择

- 接入 `72 / 96 / 144 / 221` 四套色卡。
- 生成时仅使用当前选择的色卡。
- 颜色统计按当前色卡输出 MARD 色号和数量。

## 4. 图片上传

- 使用小程序图片选择能力，从相册或拍照选择图片。
- 支持 PNG、JPG、WEBP。
- 显示原图完整预览，图片适配固定预览区。
- 处理图片加载失败、格式异常和超大图片情况。

## 5. 参数设置

- 支持选择底板尺寸。
- 支持选择色卡。
- 支持选择合并强度 `低 / 中 / 高`。
- 支持调整图案大小百分比。
- 生成按钮在未上传图片时禁用。

## 6. 图纸生成逻辑

- 复用网页版核心算法思路。
- 使用 Canvas 或同等像素读取能力获取图片像素数据。
- 按底板尺寸和图案大小将图片缩放并居中放入正方形底板。
- 提取每格代表色，并保留小面积高对比细节。
- 匹配当前色卡中最接近的颜色。
- 执行全图颜色频率合并，减少杂色。
- 生成图纸数据和颜色统计数据。

## 7. 图纸预览

- 预览区保持正方形。
- 显示拼豆颜色块、网格线和 MARD 色号。
- 每 `5` 格显示虚线辅助线。
- 每 `10` 格显示黑色实线。
- 手机端优先保证预览区可拖动、可缩放或可切换局部查看。

## 8. 颜色统计

- 统计总豆数。
- 统计使用颜色数。
- 统计每个 MARD 色号数量。
- 以适合手机阅读的列表方式展示颜色清单。

## 9. 图片保存

- 支持将当前图纸保存为图片。
- 保存图中包含网格、色号和颜色统计。
- 处理保存失败、权限拒绝和相册写入失败情况。

## 10. 小程序交互形态

- 页面采用单列布局。
- 首屏优先展示上传区和图纸预览区。
- 参数设置和统计区域可采用分段面板、折叠区或底部抽屉。
- 生成按钮和关键操作按钮在手机上易于点击。

## 11. 性能策略

- 优先保证 `52 / 78 / 104` 三种底板流畅。
- `208 x 208` 需要重点评估生成耗时和内存占用。
- 必要时增加分阶段渲染、局部绘制或 Worker 方案。

## 12. 权限与异常处理

- 处理图片读取权限。
- 处理保存到相册权限。
- 处理用户拒绝授权后的重新引导。
- 处理生成失败、Canvas 不可用、图片解析异常等情况。

## 13. 第一版不做

- 不做手动改色。
- 不做自动去背景。
- 不做 CSV 导入导出。
- 不做多品牌色号切换。
- 不做账号系统。
- 不做云端存储。

## 14. 开发建议

- 小程序工程单独放在 `miniprogram/`。
- 将色卡、类型定义、生成算法逐步抽离到 `shared/`。
- 先完成 MVP，再补大图性能和分板查看。
